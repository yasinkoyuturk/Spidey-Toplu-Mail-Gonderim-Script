# Spidey Mass Mail Script (Toplu Mail Gönderim Scripti)

A historical archive of a classic ASP script developed by Yasin "Spidey" Koyutürk in the mid-2000s for mass email distribution.

## About This Project
This script was widely used by Turkish webmasters to manage and send mass emails via ASP infrastructure. It remains a piece of internet archaeology from the golden era of Turkish webmaster forums and communities.

**Original Release / Active Link:** [View on ASPindir](https://www.aspindir.com/Goster/5202)

**Developer:** Yasin Koyutürk ([yasinkoyuturk.com](https://yasinkoyuturk.com/))

**Note:** This code is strictly uploaded for digital archiving purposes. It is not maintained or recommended for modern server environments.
